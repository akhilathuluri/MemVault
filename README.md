# MemVault - Your Personal Memory Management System

## 📋 Overview
MemVault is a sophisticated web application designed to help users manage, store, and retrieve their personal memories, files, and data in a secure and organized manner. Built with modern web technologies, it offers a seamless user experience with powerful features for memory management.

## 🚀 Features

### 1. Authentication System
- Secure user registration and login
- Session management
- Protected routes for authenticated users
- Automatic redirection based on authentication status

### 2. Dashboard
- Overview of your memories and data
- Quick access to recent activities
- Visual representation of your memory storage
- Personalized user interface

### 3. Central Database
- Organized storage of memories and data
- Categorized content management
- Search and filter capabilities
- Data visualization tools

### 4. File Management
- Upload and organize files
- File categorization
- Secure file storage
- Easy file retrieval

### 5. Advanced Search
- Powerful search functionality
- Filter by various parameters
- Quick access to stored memories
- Search history tracking

### 6. Settings Management
- User preferences configuration
- System settings
- Notification preferences
- Personalization options

## 🛠️ Technical Stack

### Frontend
- **React 18**: Modern UI framework
- **TypeScript**: Type-safe development
- **Vite**: Fast build tool
- **TailwindCSS**: Utility-first CSS framework
- **Framer Motion**: Smooth animations
- **React Router**: Navigation management
- **Recharts**: Data visualization
- **Sonner**: Toast notifications

### Backend & Database
- **Supabase**: Backend-as-a-Service
- **Google Generative AI**: AI-powered features

### Development Tools
- **ESLint**: Code linting
- **TypeScript**: Type checking
- **PostCSS**: CSS processing
- **Autoprefixer**: CSS compatibility

## 🔧 Setup and Installation

1. **Prerequisites**
   - Node.js (v16 or higher)
   - npm or yarn package manager

2. **Installation**
   ```bash
   # Clone the repository
   git clone [repository-url]
   
   # Navigate to project directory
   cd memvault
   
   # Install dependencies
   npm install
   
   # Start development server
   npm run dev
   ```

3. **Environment Setup**
   - Create a `.env` file in the root directory
   - Add necessary environment variables (Supabase URL, API keys, etc.)

## 🚀 Getting Started

1. **Registration**
   - Create a new account using the registration page
   - Verify your email address
   - Set up your profile

2. **Using the Application**
   - Log in to your account
   - Explore the dashboard
   - Start adding memories and files
   - Use the search functionality to find your content
   - Customize settings according to your preferences
